# Hola, soy Abraham

Me gusta construir cosas que resuelvan problemas reales.

Gran parte de lo que hago nace de una pregunta sencilla:

> **¿Esto se puede automatizar, simplificar o hacer mejor?**

A partir de ahí suelo terminar diseñando una solución, conectando servicios, montando infraestructura, escribiendo software o experimentando hasta que funciona como quiero.

## 🏗️ Build → Deploy → Break → Fix → Repeat

Me gusta entender el ciclo completo de un proyecto.

Una idea puede empezar como unas cuantas líneas de código y terminar involucrando servidores, redes, almacenamiento, APIs, interfaces, automatizaciones, seguridad, monitoreo y varias cosas que probablemente no estaban contempladas al principio.

Y esa es precisamente la parte interesante.

## 🔧 Mi laboratorio

Una buena parte de mis proyectos vive en infraestructura que administro personalmente.

Eso me permite experimentar con ideas de principio a fin: desde desarrollar una aplicación hasta ponerla en funcionamiento, conectarla con otros sistemas, observar cómo se comporta y seguir mejorándola.

Algunas cosas nacen para resolver una necesidad específica.

Otras empiezan solamente por curiosidad.

Las mejores suelen ser ambas.

## 🤖 AI is a tool, not the product

Me interesa especialmente usar inteligencia artificial como una pieza dentro de sistemas más grandes.

Procesar información, entender contenido, automatizar decisiones, crear interfaces más naturales o simplemente eliminar trabajo manual.

La parte interesante no es solamente hacer que un modelo responda.

Es construir todo lo que ocurre **antes y después de esa respuesta**.

## 🚧 Siempre hay algo en construcción

Probablemente varios repositorios estén en alguna de estas etapas:

`idea` → `prototype` → `working` → `production` → `refactoring` → `why did I build it this way?` → `v2`

Algunos proyectos llegan a producción.

Otros sirven para aprender algo.

Y algunos existen simplemente porque quería saber si podía construirlos.
